# Jev

**Jev (`core/jev/`).** Optional decisions by Jev, a decision model on OpenRouter (`POST /api/alpha/decisions`, model pinned in `jevClient.ts`): a fast path before the Haiku moderator (`quickModerator.ts`, idle rooms only, null = ask Haiku), a risk hint on pending approval cards (`approvalRisk.ts`), an agent suggestion on the new-chat screen (`agentSuggest.ts`; `jev:suggestAgent` never offers a remote agent), and a per-routine webhook condition (`webhookCondition.ts`; a call that fails it is a `skipped` run with no chat). `jev.ts` gates each on `jev.json` (the key, written 0600, and a master switch plus one per feature, set from **Settings › Jev decisions**, `JevSettings.tsx`). Off, without a key, or on any Jev failure, every caller does exactly what it did before Jev. The risk hint is never read by anything that answers a request. The key never goes to the UI, logs or error messages. Design: `docs/superpowers/specs/2026-10-30-jev-decisions-design.md`.
