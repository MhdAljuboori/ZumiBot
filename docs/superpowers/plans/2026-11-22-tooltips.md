# App Tooltips Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every native `title` tooltip in the frontend with one app-drawn tooltip driven by `data-tip`.

**Architecture:** A single `TooltipLayer` mounted beside the app listens on `document` for hover and keyboard focus,
finds the nearest `[data-tip]` and draws one bubble in a portal. Pure rules (placement, timing, when a tip is needed)
live in `src/state/tooltip.ts`. Every `title=` on a DOM element becomes `data-tip=`; a guard test keeps it out.

**Tech Stack:** React 19, plain CSS with `tokens.css` variables, vitest (node environment).

**Spec:** `docs/superpowers/specs/2026-11-22-tooltips-design.md`

## Global Constraints

- No `title` attribute and no SVG `<title>` in `zumi-bot-server/frontend/src/**/*.tsx`.
- No new dependency.
- Show after 500 ms; at once while a tip is open or within 300 ms after one closed.
- Bubble: `--bg-raised`, `1px solid var(--border)`, `--shadow-pop`, 8 px radius, 12 px text, max 320 px wide, keeps line
  breaks, `pointer-events: none`; 6 px from the target, 8 px inside the window.
- Never commit (user rule); the user commits.

## Review Focus

- Disabled button with a tip (the reason it cannot act): the tip must still show on hover.
- Tip text changing while shown (`Copy code` → `Copied`): the bubble updates in place.
- Target removed or scrolled away while its tip shows: the bubble hides, never floats over nothing.
- Nested tipped elements (a tipped chip inside a tipped row): the innermost wins.
- Icon-only button whose `title` was its only name: it keeps that name through `aria-label`.

- Test: `zumi-bot-server/frontend/tests/tooltip.test.ts`

**Interfaces:**

  - `SHOW_MS = 500`, `WARM_MS = 300`, `GAP = 6`, `MARGIN = 8`
  - `type Box = { left: number; top: number; width: number; height: number }`

  - `showDelay(now: number, open: boolean, lastHiddenAt: number | null): number`

  - `describes(tip: string, name: string): boolean` — whether the target needs `aria-describedby`

  `showDelay` is 0 when open or `now - lastHiddenAt < WARM_MS`, else `SHOW_MS`; `tipNeeded` false for blank tips,
  equal-to-own-text tips need `truncated`, other tips always true (whitespace-trimmed compare); `describes` false when the

### Task 2: Tooltip layer and look

**Files:**
- Create: `zumi-bot-server/frontend/src/components/TooltipLayer.tsx`, `zumi-bot-server/frontend/src/styles/tooltip.css`
- Modify: `zumi-bot-server/frontend/src/main.tsx` (render `<TooltipLayer />` beside `<App />` inside `StrictMode`),
  `zumi-bot-server/frontend/src/styles/index.css` (import `tooltip.css` last)

**Interfaces:**
- Consumes: Task 1.
- Produces: `export function TooltipLayer(): ReactNode`; DOM contract `data-tip` on any element; bubble
  `.app-tip` (`role="tooltip"`, `id="app-tip"`, `data-side`).

- [ ] **Step 1: Implement the layer**: capture-phase `pointerover` / `pointerout` (mouse pens only, not touch), `focusin`
  / `focusout` (show only when the target matches `:focus-visible`), `keydown` Esc, `pointerdown`, capture `scroll`,
  `resize`, window `blur` hide. Target = `closest('[data-tip]')`; an element with `title` and no `data-tip` has it moved
  to `data-tip` first. A `MutationObserver` on the shown target (attributes `data-tip`, plus `isConnected` check on each
  tick) updates or hides. Truncation = `scrollWidth > clientWidth` on the target. Set `aria-describedby="app-tip"`
  while shown when `describes()` says so; restore the old value on hide. Place with `placeTip` after measuring the
  bubble in `useLayoutEffect`.
- [ ] **Step 2: Style** `.app-tip` per Global Constraints, `position: fixed`, `z-index: 2000`, `white-space: pre-line`,
  short fade (`opacity` 120 ms, none under `prefers-reduced-motion`).
- [ ] **Step 3: Verify** in the browser: hover a tipped button, a disabled tipped button, a truncated file name, the
  workflow canvas zoom buttons; Tab onto a tipped button. Bubble appears and places as specified.
