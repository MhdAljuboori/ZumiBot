# Room clone

**Room clone.** **Clone room…** in a room's sidebar row menu, or in its context meter popover, opens `CloneRoomDialog.tsx` (logic in the pure `state/cloneRoom.ts`; default name the old one plus " (2)", `nextCopyTitle`). `chats:cloneRoom` (`core/chat/roomClone.ts`) makes a new room through `createGroup` with the same members (same order), role and folder, plus each member's "Allow for this chat" keys (`ChatService.copyAllowed`); items, versions, side questions, attachments, snapshots, sessions, tasks, context and unread state stay behind, and the source room is never changed. **Start over** stops there. **With summary** first asks `chats:summarizeRoom` for a draft: `RoomSummaries` (`roomSummary.ts`) runs one bare `claude -p --model sonnet --tools '' --setting-sources '' --strict-mcp-config --no-session-persistence --output-format json --system-prompt …` in the room's folder, like the moderator, fed the roster with bare handles, the role, an earlier handoff, the room's Files list and its finished messages (capped at 150 000 characters, keeping the first user message and the newest). At most one call runs per room (a new one replaces it, which is how Rewrite works) and two server-wide; it times out after 3 minutes and is killed by `chats:cancelSummary` (Cancel, closing the dialog) and at server stop. The user only ever sees fixed errors, never CLI text, and its cost is recorded on the source room as `#handoff` ("Room handoff" in Usage). Only the text the user accepts in the review box (at most 12 000 characters) is stored, as `GroupInfo.handoff` `{text, from: {chatId, title}, at}`, not as an item: `buildBriefing` puts it in every member's `--append-system-prompt` on every turn, resumed or seeded, so the history cap never cuts it, and the moderator does not read it. Fork keeps it and sync carries it inside `group`. `HandoffCard.tsx` shows it collapsed at the top of the room, with a link to the source room while it exists. Rooms made by `chats:createGroup` have no stored sidebar spot, so the client places the clone right under its source (same section, or the unplaced list) by writing out the order the user sees with `placeAfter` (`state/sidebarLayout.ts`) through `sidebar:save`; a room's Fork is placed the same way (`placeUnder` in `App.tsx`). The handoff text and the transcript never go into logs, URLs or errors. Design: `docs/superpowers/specs/2026-11-04-room-clone-design.md`.
